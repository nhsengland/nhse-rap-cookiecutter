# Guides

Welcome! These short tutorials teach the good habits that make a data-science
project pleasant to work on — yours, and anyone who picks it up after you.

You don't need to read them all at once. A good order for a first project:

1. **[Project structure & why it matters](01-project-structure.md)** —
   what every folder is for, and why a tidy layout saves you time.
2. **[From notebooks to modules](02-notebooks-to-modules.md)** —
   when to move code out of a notebook into reusable files.
3. **[Virtual environments](03-virtual-environments.md)** —
   why you don't install packages "globally", and how environments help.
4. **[Git basics](04-git-basics.md)** —
   saving your work in small, labelled steps you can go back to.
5. **[Writing your first test](05-writing-a-first-test.md)** —
   proving your code does what you think, automatically.
6. **[Reading data safely](06-reading-data-safely.md)** —
   loading files in a way that fails clearly instead of mysteriously.
7. **[Making your first plot](07-making-a-first-plot.md)** —
   turning a table of numbers into a chart you can save and share.
8. **[What good looks like](08-what-good-looks-like.md)** —
   a friendly checklist to glance at before you share your work.

Each guide is self-contained and uses the code already in this project as its
example. Take your time, and tinker as you go — breaking things and fixing them
is how this sticks.
